# MLC109: empty AnimationGroup / Succession

`manim-lint` reports `MLC109` when `AnimationGroup(...)` or
`Succession(...)` is constructed with zero positional animation arguments.
Keyword arguments such as `lag_ratio` configure timing but contribute no
animations, and a memberless group cannot be compiled into a playable
animation at render time.

- Default severity: `error`
- Minimum confidence: `certain`
- Implementation phase: `1`
- Fix: none

Calls with a `*args` splat are skipped because the splat may supply
animations at runtime.

## Wrong

```python
class Demo(Scene):
    def construct(self):
        group = AnimationGroup()
        chain = Succession(lag_ratio=0.5)
```

## Right

```python
class Demo(Scene):
    def construct(self):
        square = Square()
        group = AnimationGroup(FadeIn(square), FadeOut(square))
        chain = Succession(FadeIn(square), FadeOut(square), lag_ratio=0.5)
```
