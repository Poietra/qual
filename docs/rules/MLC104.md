# MLC104: literal non-positive run_time or wait duration

`manim-lint` reports `MLC104` when a literal duration is zero or negative
on a confirmed timing call:

- `play(..., run_time=<literal <= 0>)`
- `self.wait(<literal <= 0>)` (first positional, or the `duration` /
  `run_time` keyword)
- `Wait(run_time=<literal <= 0>)`

Manim validates every duration (`Scene.validate_run_time`): a non-positive
run time cannot produce a frame and the render aborts with `ValueError`.

- Default severity: `error`
- Minimum confidence: `certain`
- Implementation phase: `1`
- Fix: none

Only literal integers and floats fire; variables, expressions, and anything
Unknown stay silent.

## Wrong

```python
class Demo(Scene):
    def construct(self):
        self.play(Create(Square()), run_time=0)
        self.wait(-1.5)
```

## Right

```python
class Demo(Scene):
    def construct(self):
        self.play(Create(Square()), run_time=2)
        self.wait(0.5)
```
