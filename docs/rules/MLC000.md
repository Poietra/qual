# MLC000: Python source cannot be parsed

`manim-lint` reports `MLC000` when a selected Python source cannot be decoded,
tokenized, or parsed for the configured `target-python` version.

- Default severity: `error`
- Minimum confidence: `certain`
- Implementation phase: `0`
- Fix: none

The file does not proceed to semantic analysis, but analysis of every other
selected file continues. Locations use one-based Unicode character columns,
including when non-ASCII text occurs before the syntax error.

PEP 263 encoding declarations accept both WHATWG labels and CPython codec
names/aliases (`latin-1`, `cp932`, `koi8_r`, ...). A declared codec that
CPython knows but the linter cannot represent is reported as "not
supported by manim-lint" — an explicit linter limitation, never a claim
that the target Python would fail to decode the file.
