# Knowledge profiles

Reviewed, versioned JSON descriptions of Manim semantics (DESIGN §5.4).

- `v0_20.json` (TODO, phase 1): upstream Manim Community 0.20 public
  semantics.
- `local_*.json`: optional local fork overlays that replace entries of a
  `base_profile` by qualified symbol and list removals in `deleted_symbols`.

Profiles are generated by a sync tool from static Manim source, reviewed by a
human, and committed; they are never regenerated during a lint run.
